# Funções Recursivas em Java

Exercício de estudo da matéria de Lógica de Programação (UCSAL).

## Sobre

Implementação de algumas funções clássicas usando recursão em Java. Com o objetivo de praticar como resolver problemas quebrando eles em casos menores até chegar no caso base.

## O que tem no código

- **Fatorial** – calcula o fatorial de um número
- **Exponenciação** – calcula a potência de um número (n^x)
- **Soma em cadeia** – soma todos os números de 1 até n
- **Divisão por subtração** – divide dois números subtraindo repetidamente
- **Inversão de vetor** – inverte os elementos de um array

## Tecnologias

- Java (sem bibliotecas externas)
